# Règles du projet

## Interface utilisateur

- Ne jamais utiliser d'émojis dans l'interface utilisateur, y compris dans les libellés, boutons, menus, messages et éléments générés dynamiquement.
- Utiliser les icônes SVG locales du sprite servi à `/icons.svg` pour les pictogrammes.
- Garder les icônes accessibles (icônes décoratives masquées aux lecteurs d'écran et icônes informatives dotées d'un intitulé accessible).
- Ne pas charger de bibliothèque d'icônes ni de ressource distante.
